O que muda de Java 17 para Java 21?

Ao usar este roteiro para a 1Z0-830, revise também as funcionalidades introduzidas após Java 17. Entre os destaques finalizados em Java 21 estão:

  • Pattern matching para switch: padrões em rótulos e verificações de exaustividade.
  • Record patterns: decomposição de valores de records em padrões.
  • Virtual threads: threads leves para aplicações com muitas tarefas bloqueantes.
  • Sequenced Collections: interfaces de coleções com ordem de encontro definida e operações nas extremidades.

Esta lista serve como orientação de versão, não como transcrição do blueprint do exame. Confirme no guia oficial quais objetivos e funcionalidades são cobrados, inclusive a disponibilidade de recursos em preview.

Como aproveitar este portal
