Fundamentos antes da trilha

Se esta é sua primeira experiência com Java, faça esta aula antes de estudar tipos e operadores. Você vai escrever um programa que lê uma resposta, guarda valores em variáveis e mostra um resultado.

  1. Identificar a classe e o método main que iniciam um programa.
  2. Declarar variáveis, atribuir valores e usar tipos como String e int.
  3. Exibir mensagens, ler texto pelo console, compilar com javac e executar com java.

Prepare o ambiente

  1. Instale um JDK 17 e abra um terminal na pasta em que vai praticar.
  2. Confirme a instalação executando java -version e javac -version.

Se o terminal não reconhecer java ou javac, revise a instalação e a configuração do PATH do sistema antes de avançar.

Seu primeiro programa com variáveis e entrada

Abra o arquivo FundamentosJava.java. Ele contém o programa completo; o nome do arquivo corresponde à classe pública. A variável nome guarda texto, idade guarda um inteiro, e a atribuição guarda em proximaIdade o resultado de uma expressão.

Exemplo completo
import java.util.Scanner;

public class FundamentosJava {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Qual é seu nome?");
        String nome = scanner.nextLine();

        System.out.println("Qual é sua idade?");
        int idade = scanner.nextInt();

        int proximaIdade = idade + 1;
        System.out.println("Olá, " + nome + "! No próximo ano você terá " + proximaIdade + ".");
    }
}

No PowerShell, compile e execute a partir da raiz do repositório:

New-Item -ItemType Directory -Force target\bin | Out-Null
javac -d target\bin src/java_Basico/FundamentosJava.java
java -cp target\bin FundamentosJava

No macOS/Linux, use o terminal:

mkdir -p target/bin
javac -d target/bin src/java_Basico/FundamentosJava.java
java -cp target/bin FundamentosJava

Digite Ana e depois 20. A saída esperada será:

Qual é seu nome?
Qual é sua idade?
Olá, Ana! No próximo ano você terá 21.

System.out.print mantém o cursor na mesma linha; System.out.println termina a linha. Scanner.nextLine lê o nome digitado. O método main é o ponto de entrada; javac compila o arquivo e java executa a classe compilada.

PRATIQUE AGORA

Faça uma alteração e teste

Troque a pergunta para “Qual linguagem você está aprendendo?” e imprima uma segunda confirmação. Depois informe outros valores e verifique a saída.

Concluído quando: o arquivo compilar, ler as duas entradas e imprimir uma resposta com o valor informado.

CHECAGEM RÁPIDA

O que a variável idade guarda depois de int idade = 20;?

Conferir resposta comentada

Guarda o valor inteiro 20. A declaração cria a variável e a atribuição inicializa seu valor; em Java, variáveis locais precisam receber valor antes do uso.

Erro comumSe o compilador disser que a classe pública deve estar em outro arquivo, confira se o nome é exatamente FundamentosJava.java. Java diferencia maiúsculas de minúsculas.

Trilha passo a passo

Os capítulos completos continuam organizados por domínio do exame; aqui os fundamentos essenciais vêm primeiro e os assuntos estão reordenados por dependência. Os detalhes de prova ficam para a seção de aprofundamento.

1. Primeiros programas

Aprenda a ler e escrever pequenos programas antes de estudar APIs maiores.

  1. 01
    Tipos primitivos e classes wrapper

    Os oito primitivos: boolean, byte, short, char, int, long, float e double.

  2. 02
    Operadores, expressões e conversões

    Monte expressões com casts, operadores prefixados/pós-fixados e curto-circuito. Para cada uma, anote a ordem de avaliação, o tipo de cada subexpressão e o resultado final.

  3. 03
    Texto com String e StringBuilder

    Preveja o conteúdo final após uma sequência de chamadas encadeadas e diferencie mutação de criação de novos objetos.

  4. 04
    Estruturas condicionais e switch

    Reescreva um switch tradicional como expressão. Verifique quais caminhos retornam valor e quais precisam de default ou yield.

  5. 05
    Laços e desvios

    Trace laços aninhados com break e continue rotulados e registre cada valor impresso e quantas vezes o corpo é executado.

  6. 06
    Métodos, sobrecarga e varargs

    Assinatura, modificadores, tipo de retorno, parâmetros e corpo de métodos.

Marco: explique um conceito sem copiar e faça uma pequena alteração no exemplo.

2. Organize o código com objetos

Modele dados e responsabilidades em classes e entenda como os objetos são criados.

  1. 01
    Classes, objetos e encapsulamento

    Desenhe a sequência de inicialização de um objeto e identifique o estado observado por cada método chamado.

  2. 02
    Construtores e inicialização

    Construtor padrão fornecido pelo compilador somente quando nenhum construtor é declarado.

  3. 03
    Interfaces e enums

    Implemente duas interfaces com métodos default de mesmo nome e resolva explicitamente o conflito na classe.

  4. 04
    Herança, sobrescrita e polimorfismo

    Trace chamadas de método e acesso a campos usando variáveis de tipos declarado e real diferentes. Justifique cada resultado.

Marco: explique um conceito sem copiar e faça uma pequena alteração no exemplo.

3. Trabalhe com dados e falhas

Guarde coleções de dados, restrinja seus tipos e trate situações inesperadas.

  1. 01
    Arrays

    Compare arrays com ==, equals e Arrays.equals; teste ordenação e busca binária com os pré-requisitos corretos.

  2. 02
    Interfaces e implementações de coleções

    Escolha uma implementação para cada cenário e explique como ordem, duplicatas, mutabilidade e chave afetam o resultado.

  3. 03
    Generics

    Classes, interfaces e métodos genéricos; parâmetros de tipo e inferência.

  4. 04
    Hierarquia e tipos de exceção

    Hierarquia Throwable, Error, Exception e RuntimeException.

  5. 05
    try, catch, finally e multi-catch

    Monte uma tabela de fluxo para métodos com return no try e no finally. Evite depender de retorno ou lançamento de exceção dentro de finally.

Marco: explique um conceito sem copiar e faça uma pequena alteração no exemplo.

4. Use APIs do dia a dia

Aplique os fundamentos para transformar dados, usar arquivos e lidar com datas.

  1. 01
    Interfaces funcionais, lambdas e method references

    Converta lambdas em method references quando adequado e explique qual método é chamado e como os argumentos são associados.

  2. 02
    Streams e pipelines

    Criação de streams a partir de coleções, arrays, valores e Stream.of.

  3. 03
    NIO.2: Path e Files

    Path, Paths/Path.of, resolução, normalização e comparação de caminhos.

  4. 04
    Data e hora com java.time

    Tipos imutáveis: LocalDate, LocalTime, LocalDateTime, ZonedDateTime e Instant.

Marco: explique um conceito sem copiar e faça uma pequena alteração no exemplo.

Projeto incremental: lista de tarefas

Construa uma aplicação de console sem frameworks. Cada checkpoint parte do anterior e precisa compilar antes de avançar. Salvar em arquivo é uma etapa opcional de aprofundamento.

Ponto de partida compilável

O primeiro checkpoint já tem uma versão mínima executável. Abra ListaTarefas.java, compile, execute e digite uma descrição antes de fazer alterações.

Ver código inicial
import java.util.Scanner;

public class ListaTarefas {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Digite uma tarefa:");
        String descricao = scanner.nextLine();

        System.out.println("Tarefa adicionada: " + descricao);
    }
}

No PowerShell, crie a pasta de saída e execute o programa:

New-Item -ItemType Directory -Force target\bin | Out-Null
javac -d target\bin src/java_Basico/ListaTarefas.java
java -cp target\bin ListaTarefas

  1. 1. Capturar e mostrar uma tarefa

    Leia uma descrição com Scanner e mostre uma confirmação. Esta primeira versão deve compilar e funcionar sem classes adicionais.

    Teste de conclusão: Entrada: estudar Java. Saída esperada: Tarefa adicionada: estudar Java.

    Revise: Tipos primitivos e classes wrapper · Texto com `String` e `StringBuilder` · Abrir código inicial
  2. 2. Guardar várias tarefas

    Troque a variável única por ArrayList<String>. Permita adicionar mais de uma tarefa e listar todas com um laço.

    Teste de conclusão: Adicione duas tarefas; ao listar, as duas aparecem na ordem de inclusão.

    Revise: Arrays · Interfaces e implementações de coleções · Laços e desvios
  3. 3. Criar um menu

    Adicione opções para incluir, listar e sair. Separe ações em métodos e repita o menu até a opção de saída.

    Teste de conclusão: Escolha sair: o programa termina sem imprimir o menu novamente.

    Revise: Métodos, sobrecarga e varargs · Estruturas condicionais e `switch` · Laços e desvios
  4. 4. Modelar cada tarefa

    Substitua String por uma classe Tarefa, com descrição e estado concluído encapsulados.

    Teste de conclusão: Crie uma tarefa e consulte a descrição e o estado por métodos públicos.

    Revise: Classes, objetos e encapsulamento · Construtores e inicialização
  5. 5. Concluir e validar

    Permita concluir uma tarefa pela posição. Verifique a posição antes de acessar a lista e mostre uma mensagem se não for válida.

    Teste de conclusão: Teste a primeira posição, a última posição e uma posição inexistente; nenhuma entrada inválida deve encerrar o programa.

    Revise: Estruturas condicionais e `switch` · Hierarquia e tipos de exceção
  6. 6. Salvar em arquivo (opcional)

    Quando as etapas anteriores estiverem funcionando, grave e carregue as tarefas em arquivo local com recursos fechados corretamente.

    Teste de conclusão: Feche e reabra o programa: as tarefas salvas continuam disponíveis.

    Revise: NIO.2: `Path` e `Files` · Try-with-resources

Como saber se pode avançar

  • Consegue explicar o objetivo do código com suas próprias palavras.
  • Compila e executa o exemplo sem copiar uma solução completa.
  • Consegue alterar uma entrada e prever como o resultado muda.
  • Resolveu o marco da etapa; anote dúvidas e retorne ao assunto se precisar consultar a resposta toda vez.
